# 📚 Estudos de Python - Udemy

Repositório dedicado ao acompanhamento de aulas, anotações e resolução de exercícios do curso de Python na Udemy.

---

## 🗂️ Estrutura do Repositório

```text
udemy/
├── 01_logica_de_programacao/
│   ├── aulas/
│   │   ├── 01_tipos_e_variaveis.py     # Tipos primitivos (str, int, float, bool) e print
│   │   ├── 02_operadores.py            # Operadores aritméticos, relacionais e lógicos
│   │   ├── 03_fatiamento.py            # Fatiamento de strings e função len
│   │   ├── 04_interpolacao.py          # Formatação e interpolação de strings (f-strings, %)
│   │   ├── 05_exceptions.py            # Tratamento de erros e exceções (try / except)
│   │   ├── 06_identidade.py            # Identidade de objetos (id, is, is not, None)
│   │   ├── 07_repeticao_while.py       # Laços de repetição com while
│   │   ├── 08_while_else.py            # Estrutura while / else
│   │   ├── 09_intro_for_in.py          # Introdução ao laço for in e range
│   │   └── 10_listas.py                # Listas (métodos append, insert, pop, del)
│   └── projetos/
│       ├── exercicios_fixacao.py       # Exercícios práticos de lógica
│       └── calculadora.py              # Mini projeto de calculadora com while
├── .gitignore
└── README.md
```

---

## 🚀 Como Executar os Códigos

1. Certifique-se de ter o Python 3 instalado:
   ```bash
   python --version
   ```

2. Clone o repositório ou navegue até a pasta:
   ```bash
   git clone https://github.com/Mauricio-Siqueira/Estudos.git
   cd Estudos
   ```

3. Execute qualquer um dos scripts:
   ```bash
   python 01_logica_de_programacao/aulas/01_tipos_e_variaveis.py
   python 01_logica_de_programacao/projetos/calculadora.py
   ```
